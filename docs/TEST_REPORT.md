## 复测入口

`bash build.sh` 会构建并运行不修改网络设置的检查。

`python3 script/check-cached-actions.py` 是自愿执行的本机控制回归测试，会临时改变真实代理设置并恢复；只适用于该脚本说明的默认无密钥测试环境，不自动运行。

`tests/delay-smoke.swift` 调用真实测速实现，检查 Selector 与模式未变。它会产生少量外网探测流量，不执行节点或模式切换。

`tests/ports-smoke.swift` 只读检查控制接口发现和运行端口；`script/check-auto-ports.py` 是自愿执行的本机回归，会临时修改 Meta 监听端口与真实代理状态并完整恢复，仅适用于脚本说明的测试环境。
