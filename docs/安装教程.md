# Clash Meta 桌面小组件安装教程

适用：`v1.0.0-preview.2`，构建 10。使用者不需要安装 Xcode、Command Line Tools、Python 或 Git。

## 下载与安装

1. 打开 [构建 10 下载页](https://github.com/TomyDeskLab/clash-meta-widget/releases/tag/v1.0.0-preview.2)。
2. 在 Assets 下载 `Clash-Meta-Widget-1.0-build10-macos-universal.zip`，不要选 `Source code`。
3. 解压，把 `Clash Meta Switch.app` 拖到“应用程序”。先退出旧的小组件宿主，再替换旧版，旧副本移到废纸篓。不要删除 ClashX Meta 本体。
4. 从“应用程序”打开一次。正常启动没有窗口，宿主在后台同步状态。
5. 桌面空白处右键 →“编辑小组件”→ 搜索 `Clash Meta` → 添加中号卡片。

要求 macOS 14 或更新系统，已运行 ClashX Meta（应用标识 `com.metacubex.ClashX.meta`）。包内包含 Apple 芯片和 Intel 架构，目前只在 Apple 芯片 Mac 上实测。工具不安装或替换 Meta，不控制 TUN，也不支持任意 Clash 客户端。

升级后若已有卡片显示链接无效，移除并重新添加一次。小号可右键改成中号。

## 首次安全提示

当前包使用本地临时签名，没有 Apple Developer ID 签名和公证，首次下载运行可能被 macOS 阻止。

核对来源后，可按系统提供的“系统设置 → 隐私与安全性 → 仍要打开”处理。此确认由使用者自己决定。不要全局关闭 Gatekeeper，也无需安装 Xcode。若提示恶意软件、损坏或没有相应选项，先核对文件并反馈，不要一概跳过安全提示。

可从同一下载页取 `SHA256SUMS.txt`，在 ZIP 所在目录运行 `shasum -a 256 -c SHA256SUMS.txt` 核对文件一致性。摘要不是公证或无漏洞证明。

## 桌面操作

| 入口 | 用途 |
| --- | --- |
| 电源图标 | 按实际状态开启或关闭系统代理 |
| 节点左右箭头 | 在当前策略组前后切换选择 |
| 规则／全局／直连 | 设置对应模式 |
| ⚙ 设置 | 主动打开节点与模式窗口 |

普通控制按钮不会自动打开管理窗口，失败信息留在卡片上。小号只有开关，中号才有节点、模式及设置入口。macOS 负责刷新卡片，显示可能晚于实际操作；在 Meta 中可核对真实状态。

## 手动选节点与测速

点中号卡片的“⚙ 设置”，可选择策略组、搜索节点并点击节点名称切换。

- 每行右侧显示连接延迟（ms），点数值或“测速”单独测该项。
- “测当前列表”批量测当前搜索结果，最多同时 3 项；“停止”取消剩余任务。
- 绿色低于 200 ms，橙色 200–499 ms，红色为更高延迟或失败。
- 打开时可以先显示 Meta 已有记录；手动测速会更新结果。

这里测的是连接响应时间，不是下载带宽。测速经指定节点访问固定的 Google HTTPS 204 页面，产生少量探测流量，不主动更换节点或模式。关闭窗口后组件继续工作。

## 兼容设置

默认系统代理端口为 `7890`，控制接口端口为 `9090`。如果现有 Meta 配置不同，或启用了接口 `secret`，在设置窗口展开“兼容设置”填写对应值。接口地址固定为本机 `127.0.0.1`，密钥只存入 macOS 钥匙串。

也可运行 `open 'clash-meta-switch://settings'` 主动打开设置。首次开关若出现系统自动化授权提示，其用途是允许调用 ClashX Meta 官方开关命令。

## 验证范围与排查

本机已实测节点窗口的单项测速、8 项批量测速和停止，并核对系统代理、模式、Selector 选择未变。重复开关、模式和节点操作入口也有回归测试。桌面全部按钮端到端、全新 Mac 首次授权、Intel 和旧系统尚未完整验收，因此继续标为预览版。

找不到组件时，先确认只保留“应用程序”里的一份 App 并打开过一次，再重新进入组件选择器。组件显示未运行时，先启动 ClashX Meta。重启后没有更新时，打开一次宿主恢复后台采样；目前不安装登录启动项。

卸载时移除桌面卡片，退出小组件宿主，再把 App 移到废纸篓。此操作不改变 Meta 当前代理状态。

维护者构建需要开发工具，普通下载使用者不需要。更多信息见 [当前测试记录](./TEST_REPORT.md)、[开发说明](./DEVELOPMENT.md) 和 [安全说明](../SECURITY.md)。
