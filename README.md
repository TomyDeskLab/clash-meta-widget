# Clash Meta Widget

**在 Mac 桌面上开关代理、切换节点和模式。**

为已经运行的 **ClashX Meta** 提供原生 WidgetKit 桌面小组件，支持手动节点管理和连接延迟测速。

**[下载最新版安装包](https://github.com/TomyDeskLab/clash-meta-widget/releases/download/v1.0.0-preview.3/Clash-Meta-Widget-1.0-build11-macos-universal.zip)** · [安装教程](./docs/安装教程.md) · [发布页面](https://github.com/TomyDeskLab/clash-meta-widget/releases/tag/v1.0.0-preview.3)

当前版本：**v1.0.0-preview.3 · 构建 11**。下载 ZIP 即可安装，**不需要 Xcode 或命令行开发工具**。

## 能做什么

| 位置 | 功能 |
| --- | --- |
| 小号桌面组件 | 查看状态、开关系统代理 |
| 中号桌面组件 | 开关代理、前后切节点、切换规则／全局／直连 |
| 中号「⚙ 设置」 | 手动打开窗口，搜索节点、选择策略组及模式 |
| 节点列表右侧 | 显示延迟 ms，点击单项测速，或批量测试当前列表 |

桌面组件由 macOS 管理位置和外观。普通控制按钮不自动弹窗；需要节点管理窗口时，手动点“⚙ 设置”。关闭窗口后，组件继续工作。

## 三步开始

1. **下载安装**：解压 ZIP，把 `Clash Meta Switch.app` 拖到“应用程序”。
2. **打开一次**：保持 ClashX Meta 运行，打开小组件 App；默认在后台工作，没有主窗口。
3. **添加组件**：桌面空白处右键 → 编辑小组件 → 搜索 `Clash Meta` → 添加中号。

> 当前包未经过 Apple Developer ID 签名和公证，首次下载可能被 macOS 阻止。核对来源后按系统提供的安全提示处理，详见[安装教程](./docs/安装教程.md#首次安全提示)。无需关闭系统安全保护。

## 节点测速

在设置窗口里，点节点右侧的“测速”或已有数值即可重新测试。“测当前列表”会批量测试搜索结果，最多同时 3 项，支持停止。

- **绿色**：低于 200 ms。
- **橙色**：200–499 ms。
- **红色**：500 ms 以上，或超时／失败。

测试的是连接响应时间，**不是下载带宽**。测速不会主动更换节点、模式或系统代理；打开窗口时可以先显示 Meta 已有记录。

## 使用要求

| 项目 | 要求 |
| --- | --- |
| 系统 | macOS 14 或更新版本 |
| 客户端 | ClashX Meta，应用标识 `com.metacubex.ClashX.meta` |
| 架构 | 包含 Apple 芯片与 Intel；已在 Apple 芯片实测，Intel 实机待验证 |
| 端口 | 默认自动读取 Meta 当前的 HTTP、SOCKS、混合端口与本机控制接口；读取失败时可手动设置 |

开关控制的是系统代理，不控制 TUN，也不负责启动或替换 Meta。控制地址固定为本机 `127.0.0.1`；可选接口密钥保存在 macOS 钥匙串。

当前仍为预览版：节点窗口测速已通过实际点击验证；桌面全部按钮、全新 Mac 首次授权、Intel 与旧系统尚未完成完整验收。详细结果见[测试记录](./docs/TEST_REPORT.md)。
